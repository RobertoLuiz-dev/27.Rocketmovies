# 🎬 RocketMovies

RocketMovies é uma aplicação web desenvolvida com React e Vite que permite aos usuários registrar, avaliar e organizar seus filmes favoritos. Esta aplicação é parte de um desafio prático com o objetivo de consolidar conhecimentos em desenvolvimento frontend moderno.

## 🚀 Tecnologias Utilizadas

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [ESLint](https://eslint.org/)
- [Node.js](https://nodejs.org/) — para execução do ambiente de desenvolvimento


## ✨ Funcionalidades (em desenvolvimento)

- Cadastro de filmes com título, descrição, nota e tags
- Listagem e visualização de detalhes dos filmes
- Sistema de avaliação com estrelas
- Interface responsiva
- Autenticação de usuários (em breve)
- Integração com backend (em breve)
